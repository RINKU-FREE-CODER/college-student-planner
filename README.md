# Campus Planner

A simple, responsive college planner for weekly classes, assignments, and exams. It runs in your browser and does not need a build step or package installation.

## Run it

Open `index.html` in a modern browser. To open the project in VS Code, choose **File → Open Folder** and select this repository folder.

## Use the planner

- Add a class, assignment, or exam with the **Quick add** form.
- Use the sidebar tabs to browse your classes and deadlines.
- Mark assignments complete or remove entries from their list.
- Your entries are stored in this browser on this device using local storage.

The first launch includes example entries to show how the dashboard works. You can remove them from the relevant list.
